# Component rights map

| Component | Treatment |
|---|---|
| Original manuscript, current package prose, original claims/data/certificates | CC0-1.0, subject to the rights holder's authority; see LICENSE |
| Original project executable code in code/ and checks/ | MIT; see LICENSE-CODE |
| Third-party research papers and quoted material | Upstream rights; citation is not relicensing |
| Supplied reviewer reports or historical reviews with unestablished rights | NOASSERTION; no CC0/MIT grant is made |
| Python, python-flint, FLINT/Arb and other dependencies | Their upstream licences; not relicensed or represented as original project code |
| Fonts embedded by PDF generation | Their upstream terms; final font inventory/embedding review pending |

The supplied external review is not copied into these current documents. Historical review files, if distributed, must have permission established or be excluded from the public payload; this map does not manufacture a licence. A summary of factual objections and dispositions is distinct from reproducing an entire third-party report.

Final release rights checking must inspect the actual frozen inventory, including any newly generated PDF and any retained historical records. The licence files alone are not that check.
